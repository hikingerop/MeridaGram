# MeridaGram — памятка для Claude

Форк Telegram Android 13.1.1 со встроенным Merida VPN. Владелец (15 лет, Россия) пишет по-русски с телефона,
не программист: отвечай по-русски, коротко, без жаргона. Работаем прямо в `main`.

## Сборка
- Собирается только на GitHub Actions (`build.yml`, ~20–25 мин, `:TMessagesProj_AppStandalone:assembleAfatStandalone`).
  APK — в артефакте `MeridaGram-N` (zip с app.apk) и в релизе `build-N`. Скачать через GitHub MCP
  (`download_workflow_run_artifact` + curl) и прислать владельцу через SendUserFile.
- `concurrency` с cancel-in-progress: пуш во время сборки её отменяет. Пока идёт сборка — коммить с `[skip ci]`,
  потом `run_workflow build.yml ref main`.
- Перед пушем: `javac` по изменённым файлам и фильтр синтаксических ошибок (expected/illegal/unclosed/…).
  Для проверки Android API есть приём: скачать `platform-34` android.jar с dl.google.com и собрать новый класс со стабами.
- В строках Android апостроф экранировать: `\'`.
- api_id/api_hash — только в секретах GitHub (TG_API_ID, TG_API_HASH), не в коде и не в чате.

## Свои классы
`TMessagesProj/src/main/java/org/telegram/messenger/merida/`: MeridaVpn, XrayConfig, MeridaGhost (призрак),
MeridaSpy (удалённые сообщения), MeridaPlayer (эквалайзер/бас/громкость/таймер/по чатам), MeridaCrypto
(шифрование поверх Telegram, маркер `🔐MG1:`), MeridaSessions (детектор новых входов), MeridaExif (очистка фото).
Настройки — `utils/settings/MeridaSettings.java`, экран — `ui/MeridaSettingsActivity.java` (разделы:
Merida Proxy (бывш. VPN), Призрак, Шпион, Плеер, Безопасность (+шифрование), Оформление, Основные).
Правила владельца: каждая новая функция включается ТОЛЬКО в «Настройках MeridaGram»; новых разделов не плодить —
класть в Основные / Оформление / Безопасность; под КАЖДЫМ переключателем — описание, что он делает (descForRow).
Меню в чате/плеере — лишь быстрый доступ, пока функция включена. В интерфейсе называть «Merida Proxy», не VPN.

## Сделано
Меню разделов, призрак, шпион, снег (+шапка, превью), название MeridaGram в шапке, иконка (фиолетовый
самолётик с улыбкой на сиреневом), продвинутый плеер, «Разрешить скриншоты» (кроме секретных чатов,
исчезающих и платных медиа), шифрование поверх Telegram, детектор входов, очистка EXIF у фото-файлов,
приватность мини-приложений (UA без модели, без сторонних куки), «Скорость Telegram» в разделе VPN,
«Скрыть вкладки папок» (Оформление), «Скопировать ID» отправителя в меню сообщения (свой переключатель в «Основных»).
Канал проекта: @MeridaGram.

2. Голосовой морфинг — сложно, в конце.
3. «Визуал» (договорено с владельцем): подарки/NFT из каталога, баланс звёзд, значок Premium — ТОЛЬКО на
   своём телефоне, ничего не отправляется в Telegram, и везде заметная пометка «визуал», чтобы скриншотом
   нельзя было никого обмануть. Без пометки или «видно другим» — не делать.
- Свой ключ подписи создан (JKS, alias `meridagram`, SHA-256 сертификата
  `8B:FC:EC:AC:2C:67:CC:02:32:61:B3:34:30:67:55:5E:EC:1A:4E:2D:26:B0:95:B9:22:6D:48:E1:68:4D:7B:D9`).
  Сборка берёт его из секретов MERIDA_KEYSTORE и MERIDA_KEYSTORE_PASSWORD (шаг «Use own signing key»).
  Когда владелец добавит секреты и сборка пройдёт с «Signing with own key» — добавить в приложение проверку
  подписи (при чужой подписи — окно «Это неофициальный MeridaGram»). Копия ключа только у владельца.
- Шифрование всей базы — не делаем (риск потерять чаты), вместо него код-пароль Telegram с отпечатком.

## Нельзя
Слежка за другими людьми без согласия: «кто заходил в профиль» (Telegram это не отдаёт — только обман),
радар онлайна/графики сна, тайное сохранение чужих одноразовых медиа, экстренная смена 2FA. Секреты в код не класть.
